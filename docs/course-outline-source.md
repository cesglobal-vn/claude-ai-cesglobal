## Đối tượng học viên

Nhân viên văn phòng, quản lý, freelancer, chủ SME muốn dùng Claude sâu cho công việc.
Yêu cầu đầu vào: biết dùng máy tính cơ bản, KHÔNG cần biết lập trình.

## Triết lý khóa học

- Làm trên chính tài liệu và dữ liệu công việc thật của học viên.
- Mỗi buổi phải ra được 1 sản phẩm dùng được ngay.
- Buổi 1-3: Claude trên web. Buổi 4-6: chuyển sang Claude Code.

## Chi tiết 6 buổi

### Buổi 1 - Làm quen và thiết lập Claude
- Giới thiệu giao diện Claude, cách ra lệnh hiệu quả bằng tiếng Việt
- Hướng dẫn Claude hiểu công việc, cách làm và yêu cầu riêng
- Nạp bối cảnh và tài liệu nền
- **Sản phẩm:** 1 trợ lý Claude được thiết lập theo công việc thực tế

### Buổi 2 - Tạo công cụ làm việc bằng Claude
- Biến ý tưởng thành web app, biểu mẫu hoặc bảng theo dõi
- Tạo công cụ chạy được ngay mà không cần viết code
- Tạo link để chia sẻ công cụ cho đồng nghiệp
- **Sản phẩm:** 1 công cụ / web app có thể sử dụng và chia sẻ

### Buổi 3 - Kết nối Claude với dữ liệu công việc
- Cho Claude đọc và làm việc với dữ liệu từ Google Drive, Gmail, Google Sheets
- Lấy dữ liệu từ nhiều nguồn và tổng hợp lại
- Cập nhật báo cáo tự động từ dữ liệu công việc thật
- **Sản phẩm:** Claude lấy được dữ liệu và cập nhật báo cáo tự động

### Buổi 4 - Cho Claude làm việc trực tiếp trên máy tính
- Cài đặt và sử dụng Claude Code (có trợ giảng hỗ trợ)
- Dùng Claude để đọc, tạo và chỉnh sửa file trực tiếp trên máy tính
- Mở rộng khả năng làm việc với một công cụ hỗ trợ
- **Sản phẩm:** Cài đặt và sử dụng được Claude Code + một công cụ hỗ trợ

### Buổi 5 - Tạo Skill và Agent tự động hóa
- Hướng dẫn Claude ghi nhớ cách làm một công việc cụ thể (Skill)
- Tạo Agent chuyên vai: trợ lý chỉ làm đúng một việc
- Để Claude tự thực hiện công việc theo đúng quy trình
- **Sản phẩm:** 1 Skill + 1 Agent chuyên vai

### Buổi 6 - Xây dựng quy trình làm việc tự động
- Kết hợp các nội dung đã học để Claude tự xử lý nhiều bước liên tiếp
- Ghép MCP + Agent + Artifact + lịch chạy thành quy trình hoàn chỉnh
- Dùng CLAUDE.md làm nền ngữ cảnh
- **Sản phẩm:** 1 quy trình làm việc tự động có thể áp dụng ngay

## Mạch năng lực xuyên suốt (đọc từ cấu trúc khóa)

1. Buổi 1: Ra lệnh + nạp ngữ cảnh (Project / knowledge)
2. Buổi 2: Artifact - biến ngữ cảnh thành công cụ
3. Buổi 3: Connector / MCP - nối vào dữ liệu thật
4. Buổi 4: Claude Code - rời trình duyệt, chạm vào file máy
5. Buổi 5: Skill + Subagent - đóng gói quy trình lặp lại
6. Buổi 6: Orchestration - ghép tất cả thành workflow tự chạy
